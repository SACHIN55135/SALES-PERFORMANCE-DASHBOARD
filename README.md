# SALES-PERFORMANCE-DASHBOARD
Interactive Sales Performance dashboard using SQL and Power BI


## 📌 Project Overview
This project analyzes sales performance using the Superstore dataset. The dashboard helps identify sales trends, profit performance, customer demand, and discount impact.

## 🎯 Objective
- Analyze Sales, Profit, Quantity, and Discount.
- Identify top-performing regions, states, and categories.
- Provide business insights for better decision-making.

## 🛠️ Tools Used
- SQL Server
- Power BI
- Microsoft Excel

## 📈 KPIs
- Total Sales
- Total Profit
- Total Quantity
- Average Discount

## 📊 Dashboard Features
- Sales by Region
- Profit by Region
- Sales by Category
- Profit by Category
- Top 10 States by Sales
- Top 10 Cities by Sales
- Sales & Profit by Segment
- Sales & Profit by Ship Mode
- Profit vs Discount
- Sales & Profit by Sub-Category

## 💡 Business Insights
- West region generated the highest sales.
- Technology category produced the highest profit.
- California was the top-performing state.
- Higher discounts reduced profitability.

## 🚀 Business Recommendations
- Increase focus on Technology products.
- Optimize discount strategies.
- Expand sales in high-performing regions.
- Improve profitability of low-margin categories.
